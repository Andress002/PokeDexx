# Pasos de como se creo la cuenta de azure students

1. Entrar a https://azure.microsoft.com/es-es/free/students

2. Le damos click en  **Empezar gratis**.

3. Iniciar sesión con el correo institucional (cuenta Microsoft).

4. Verificar la condición de estudiante: Microsoft envía un enlace al correo institucional lo abrirmos y confirmamos.

5. Completar el formulario: nombre, apellido, país y teléfono (verificar el número con el código que llega por mensaje).

6. Aceptar el acuerdo de cliente y hacer clic en **Sign up**.

7. Esperamos unos minutos y entrar a https://portal.azure.com

8. En **Suscripciones**, comprobar que aparece **Azure for Students** con el crédito disponible.
